# 🧠 AI Markdown Database

**Structured Markdown templates for coding assistants.**
*Think of it like npm… but for Markdown files.*

AI coding assistants are smart, but only if you tell them exactly what to do.
These templates give them structure, context, and clarity. So you can build faster and ship cleaner.

---

## 🚀 What is this?

The **AI Markdown Database** is an open-source collection of production-ready Markdown templates, designed for seamless integration with coding assistants like **Claude Code**, **Gemini CLI**, **OpenAI Codex**, and more.

Each template follows a standardized format so your assistant can understand:

* **Project intent**
* **Tech stack & architecture**
* **Business logic & constraints**
* **Design and feature requirements**

Feed a template to your favorite AI, and it’ll generate consistent, working code that matches your intent. No more prompt chaos!

---

## 🧩 How It Works

1. **Pick a template**
   Browse `/templates` for web apps, APIs, SaaS tools, bots, and more.

2. **Customize it**
   Edit the Markdown - update the stack, features, and requirements.

3. **Feed it to your assistant**
   Paste or upload into Claude, Gemini, Cursor, Windsurf, etc.

4. **Ship**
   Watch your AI code assistant deliver a working build in minutes.

---

## 💡 Why Markdown?

Because Markdown is universal. It's readable by humans *and* machines.
By standardizing instructions, we make every AI coding assistant **more predictable, faster, and less chaotic**.

---

## 🛠 Template Structure

Each file follows a consistent schema:

```markdown
# Project Title
## Overview
Short summary of what this app does.

## Features
- User authentication
- Dashboard analytics
- Stripe payments

## Tech Stack
- Frontend: React + Next.js
- Backend: FastAPI
- Database: Postgres

## Design Choices
- Design language
- Color scheme

## Business Requirements
- Multi-tenant support
- Usage tracking

## Additional Notes
Any constraints, edge cases, or vibes worth noting.
```

## 🧱 Contributing

Pull requests welcome!
If you’ve built a cool Markdown spec or think your template could help others, submit it here.

### 🧭 Contribution Guidelines

1. **Fork the repo** and create a new branch for your contribution.
2. **Add your template** under `/templates/<category>/<template-name>.md`.

   * Example: `/templates/backend/yourfile.md`
3. **Follow the schema** shown above for consistency.
4. **Keep it clean and readable** - this is for humans *and* LLMs.
5. **Add a one-liner description** in `/templates/README.md` under the right category.
6. **Submit a pull request** with a short note on what your template does.

> 🚨 No need for complex tooling, dependencies, or setup.
> Just structured Markdown — minimal effort, maximum clarity.

If you’re unsure where your template fits, open an issue and we’ll help categorize it.
